# Accessibility Steering

1. Use at least 18px base font size for primary task text.
2. Maintain WCAG AA color contrast.
3. Use large tap targets, preferably at least 44 by 44 CSS pixels.
4. Do not rely on color alone to communicate risk; use icons and text labels.
5. Use plain Japanese and English labels; avoid technical jargon.
6. Provide visible focus states for keyboard and switch-access users.
7. Every image upload must have an accessible name and preview.
8. Every task must show the original note so users can verify AI extraction.
9. Use semantic HTML, landmarks, labels, and descriptive alt text.
10. Ensure forms can be completed with keyboard input alone.
